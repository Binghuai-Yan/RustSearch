# RustSearch v0.1.9

本次发布新增 Tauri 2 桌面前端，并将 WinUI、WPF、Tauri 改为同版本、功能同步的三套独立发行包。每套均提供 Windows x64 安装 EXE 和便携 ZIP，包含共享搜索引擎、MCP 服务端及离线 OCR。已有索引、历史和设置可以继续使用，无需重建。

## 下载与升级

| 前端 | 安装版 | 便携版启动程序 |
| --- | --- | --- |
| WinUI | `RustSearch-0.1.9-WinUI-win-x64-setup.exe` | `RustSearch.WinUI.exe` |
| WPF | `RustSearch-0.1.9-WPF-win-x64-setup.exe` | `RustSearch.UI.exe` |
| Tauri | `RustSearch-0.1.9-Tauri-win-x64-setup.exe` | `rustsearch-tauri.exe` |

便携 ZIP 使用同一文件名前缀。解压时保留完整目录，直接运行对应程序。WinUI 保留旧版安装身份和默认安装目录，可升级现有安装；WPF 改为独立应用，不再放在 WinUI 的 `Compat/` 子目录。三套安装器分别注册、升级和卸载，可同时安装。Tauri 需要系统 WebView2 Runtime；WinUI/WPF 和 Tauri 的迁移组件已随包提供所需 .NET 运行时。

## 三个前端的功能同步

- 搜索、预览、文件操作、搜索历史、索引管理、暂停/恢复、OCR、自定义词典、主题、托盘、数据目录迁移及 MCP 配置使用同一功能约定。三套搜索统一每页 50 条，并直接读取同一份类型筛选配置，包含 EPUB。
- 新增 Tauri 2 + Vue 3 界面，支持浅色/深色主题、紧凑布局、中文输入组合事件、安全高亮、单实例、关闭到托盘与引擎自动重连。
- Tauri 补齐搜索历史、文件右键操作、MCP 配置复制、数据迁移/切换/取消；迁移组件复用原有校验、独占租约、回滚及源数据清理代码。
- WPF 补齐已有目录切换、迁移取消及 MCP 状态；保存设置时保留共享暂停状态，切换目录后重新加载设置。
- 三套界面共享默认数据目录、索引、搜索历史及偏好文件。设置重新打开时读取后端最新配置，主题在启动时读取共享偏好。迁移数据前需关闭其他前端及 MCP 客户端。

## 可靠性与发行改进

- 修复快速退出、重连及连续取消迁移时的引擎交接竞态：旧引擎释放索引锁后才允许新引擎接管，新连接确认引擎就绪后再处理请求。
- 修复引擎崩溃后桥接进程可能一直等待标准输入、导致界面无法及时重连的问题。关闭单个客户端不会终止仍被其他客户端使用的共享引擎。
- 统一从 `VERSION` 维护版本号，构建同时生成六个独立包及带 SHA-256 的发行清单。发布检查校验三个包的版本、共享后端/MCP/OCR 内容和必要运行时文件。
- GitHub Actions 对三套前端构建和回归，上传全部产物到草稿 Release，确认六个包和发行清单齐备后再统一公开。
- 默认卸载保留共享索引；显式选择删除索引会影响使用同一数据目录的其他前端，但保留目录中的无关文件。

## 验证与已知限制

本次功能已通过 41 项 Rust 后端测试、前端高亮安全测试、数据迁移专项测试，以及三套真实桌面和安装/卸载回归。验证覆盖中文搜索、OCR、MCP、托盘、崩溃重连、连续取消迁移、拒绝覆盖非空目录、迁移后重新打开索引及两种卸载路径。

物理鼠标拖拽和真实第三方中文输入法候选窗仍需交互桌面验收，输入组合事件模拟不能替代候选窗实测；本机符号链接迁移场景因缺少创建权限跳过。WinUI 的部分第三方输入法候选窗兼容问题仍可通过选择 WPF 版规避。

详细约定见 [功能同步说明](../frontend-parity.md)，MCP 配置见 [接入说明](../mcp.md)。
