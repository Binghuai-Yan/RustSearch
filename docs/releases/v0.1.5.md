# RustSearch v0.1.5

此版本集中修复设置、预览、数据迁移、卸载和关闭行为。索引格式未变，已有数据可直接使用。

## 修复

- 设置窗口首次打开时按 DPI 和屏幕工作区确定大小，并在布局完成后显示索引页；窄窗口可滚动访问所有设置按钮。
- 搜索结果右侧预览会自动滚动到第一个高亮词附近。WinUI 和 WPF 兼容界面均支持该定位。
- 迁移数据目录时，复制并验证新目录、重连后端并刷新搜索；成功后清理旧目录中的索引、SQLite 文件及已迁移配置，保留日志和无关文件。清理失败会在设置界面显示原因。
- 卸载时选择删除用户数据，会先请求前端退出，再清理索引、元数据库、词典、配置和界面偏好；默认卸载继续保留用户数据。
- 关闭窗口后的托盘驻留与完全退出行为经过完整进程级回归，托盘驻留后再次启动可恢复已有窗口。

## 验证

- Rust 后端 30 项单元测试和 2 项 PDF 子进程测试通过，`clippy -D warnings` 无警告。
- WinUI 长文档预览测试验证搜索词位于约 800 行之后时自动滚动；设置、迁移、托盘、后端崩溃恢复和浅深色视觉回归通过。
- WPF 兼容界面启动与搜索回归通过；隔离目录中的真实后端迁移测试通过。
- 便携 ZIP 与安装 EXE 均完成构建；安装、启动、默认保留数据卸载，以及选择删除数据卸载均通过隔离环境测试。

## 下载与说明

- `RustSearch-0.1.5-win-x64-setup.exe`：安装版。
- `RustSearch-0.1.5-win-x64.zip`：便携版，解压后运行 `RustSearch.WinUI.exe`。
- 微信输入法在 WinUI 文本框中仍可能不显示候选窗，可使用随包提供的 `Compat/RustSearch.UI.exe` WPF 兼容界面。
