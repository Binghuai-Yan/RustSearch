# 代码与发布审查（2026-10-09）

检查范围：Rust sidecar 的索引调度、监听、提取、查询和 IPC；WinUI/WPF 的进程生命周期、搜索与设置；迁移及卸载；Windows 构建脚本、GitHub Actions、Release 与 README。检查包括静态阅读、Rust 测试、前端编译、隔离目录集成测试、1 万文档基准和真实窗口视觉测试。

## 已处理的问题

| 风险 | 处理 |
| --- | --- |
| 索引队列满时添加文件夹可能一直等待 | 改为非阻塞入队；队列满立即返回 `INDEX_BUSY`，并撤销本次文件夹登记。 |
| 重复添加现有文件夹时队列满可能误删原登记 | SQLite 返回是否新插入，仅回滚本次新登记的目录。 |
| 空闲后端每 30 秒遍历所有根目录 | 兜底核对改为每 2 分钟；文件监听、队列溢出和启动核对仍即时触发。 |
| PR 也执行完整发行打包 | PR 改为静态检查、后端测试和两个前端编译；发行打包仅在 `main`、标签和手动触发时运行。 |
| 构建任务持有 Release 写权限 | 发布拆为单独的最小权限任务。 |
| Release 只有自动生成的比较链接 | 每个标签必须提供版本专属详细更新记录；v0.1.5 说明已补齐。 |
| README 截图不利于阅读，缺少失效检测 | 用真实界面重新采集和裁切，提供文件页备用链接，并在 CI 验证全部图片可解码。 |

## 验证结果

- `cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、31 项 Rust 单元测试和 2 项 PDF 子进程测试通过。
- WinUI、WPF Release 编译通过；后端集成测试覆盖 1003 份中文文件、查询、启动恢复以及 5 秒内的文件监听同步。
- 1 万文档样例索引 1.28 秒，未缓存查询 1–4 ms，新增文件 441 ms 可搜索。测试使用本机 SSD 与纯文本样例，不能外推到大型 PDF、网络盘或机械盘。
- 真实 WinUI 窗口的浅深色、五个设置页、标准和紧凑尺寸视觉检查通过。

## 后续关注

- Windows App SDK 自包含发布已在本机与安装包隔离目录测试，仍需要在无开发工具的干净 Windows 10/11 虚拟机验收。
- CI runner 没有交互桌面，不能代替本地 WinUI/WPF 自动化测试。发布前应运行 `./build.ps1 -TestInstaller`。
- 兜底扫描现在最多间隔 2 分钟；正常本地文件变更由 `notify` 处理，但不可靠的网络盘或失效的系统通知可能晚于 5 秒才被兜底扫描发现。
- Tantivy writer 固定使用约 500 MB 内存，低内存机器可考虑基于可用内存自适应。需要先记录峰值内存与索引吞吐，再调整参数。
- 当前环境访问 `raw.githubusercontent.com` 返回 502，仓库中的 PNG 已验证有效；README 为每张截图提供 GitHub 文件页链接，供图片无法内嵌加载时查看。
