# RustSearch Fluent 视觉改版方案

## 目标与范围

把已经完成的 WinUI 功能整理为适合长期使用的 Windows 本地搜索界面。参考 WinUI 3 Gallery 的窗口材质、导航、排版与状态表达，主屏围绕检索、扫描结果和阅读预览组织。

本轮保持 Windows App SDK 2.4.0、自包含非 MSIX 发布、Rust sidecar、JSON Lines 契约和数据格式。继续使用官方 IconPark 本地图标，不引入网络字体或运行时远程资源。现有索引、搜索、文件操作、数据目录切换和退出行为均纳入回归。

## 页面结构

主窗口由融合标题栏、窄导航栏、搜索工作区和底部状态栏组成：

```text
┌────────────────── RustSearch ─────────────── 原生窗口按钮 ┐
│ 导航 │ 搜索框：关键词、清空、查询状态                     │
│      │ 文件类型 / 排序                     结果数 / 刷新 │
│ 搜索 ├───────────────────┬──────────────────────────────┤
│ 历史 │ 文件名与匹配摘要    │ 文件标题 / 信息 / 文件操作     │
│ 索引 │ 路径、大小和时间    │                              │
│      │                   ↔  可选择的高亮文本预览          │
│      │ 结果列表          │                              │
│ 主题 │ 上一页 / 页码 / 下一页                            │
│ 设置 ├──────────────────────────────────────────────────┤
│ 退出 │ 文档统计 / 索引进度                   引擎连接状态 │
└──────┴──────────────────────────────────────────────────┘
```

导航栏入口必须对应真实操作：搜索定位输入框，历史打开已有查询，索引打开文件夹管理，设置打开分类设置，主题即时切换，退出执行现有完整退出流程。每个图标配工具提示和可访问名称。

搜索框保留 300 ms 防抖、回车查询、清空及过期响应取消。类型与排序紧邻搜索区域，结果数量在同一行，刷新采用轻量图标。搜索等待状态可见，完成或取消时正确收起。

## 窗口与材质

| 项目 | 规范 |
| --- | --- |
| 标题栏 | 48 DIP，自定义拖动区与系统原生最小化、最大化、关闭按钮并存 |
| 标题栏预留 | 按 SDK 右侧按钮宽度及当前缩放实时换算，避免标题和按钮重叠 |
| 外壳 | 支持时使用原生 Mica，背景透明让材质可见；不可用时回退主题纯色 |
| 工作区 | 浅色明亮表面、深色中性深灰表面；正文区域保持稳定对比度 |
| 预览区 | 与结果区以细边界和轻微表面差异区分，保持连续布局 |
| 强调色 | 采用系统强调色用于选中和必要操作，不大面积染色 |

系统关闭透明效果、进入高对比模式或硬件不支持时，优先依赖 WinUI 材质的系统回退能力。不能以增加透明效果为代价降低文字可读性。

## 视觉规范

| 元素 | 规范 |
| --- | --- |
| 页面标题 | 24 DIP、半粗体 |
| 区域标题 | 16 DIP、半粗体 |
| 文件名 | 14 DIP、半粗体、单行省略 |
| 正文 / 表单 | 14 DIP，预览采用舒适行距 |
| 路径 / 元信息 | 12 DIP，次级文字色，完整内容通过预览或工具提示访问 |
| 间距 | 使用 4、8、12、16、24 DIP 的一致节奏 |
| 工具按钮 | 常规 32 × 32 DIP，透明或轻量底色，图标约 18 DIP |
| 图标 | 官方 IconPark SVG，本地浅深版本，不重新绘制近似路径 |
| 边界 | 细分隔线；圆角通常 4 至 6 DIP，上限 8 DIP |
| 状态 | 区分悬停、按下、选中、禁用和键盘焦点，尽量采用原生状态模板 |

页面采用连续平面布局。搜索结果是重复条目，设置项以行和分隔线组织，不把整页包装成多层卡片。

## 结果与预览

结果条目按照文件名、匹配摘要、路径和文件元信息组织，压低重复按钮的存在感。文件操作集中到预览标题附近，同时保留双击、回车和右键菜单。长文件名和长路径必须省略或换行，不得撑开布局。

预览提供文件名、文件类型、大小与修改时间，操作按钮沿同一基线排列。正文保留文本选择和关键词高亮，行距独立于结果摘要。空预览、加载、提取失败、扫描件无文本和截断状态均有明确表达。

结果和预览之间保留鼠标拖动、键盘左右调整及宽度持久化。分隔条提供调整光标和焦点反馈，缩小窗口后仍保证两侧最小可用宽度。

## 设置分类

| 分类 | 内容与操作 |
| --- | --- |
| 索引文件夹 | 路径输入与浏览、根目录列表、添加、移除、重建、暂停恢复、索引统计 |
| 索引选项 | 单文件大小上限、忽略目录、自定义分词词典、固定可见的保存操作 |
| 外观与行为 | 浅深主题、关闭到托盘或完全退出；即时生效并持久化 |
| 数据存储 | 当前目录、选择新目录、迁移当前索引和设置、确认切换、失败回滚、打开目录 |
| 关于 | 版本、运行框架、图标许可及本地存储信息 |

使用原生 NavigationView 分类。窗口较宽时显示标签，紧凑窗口折叠导航，当前分类内容独立滚动。分类切换保留尚未保存的输入。设置窗口的忙状态、确认框取消、退出取消、目录切换回滚等现有逻辑继续保留。

## 实施步骤

1. 建立共享主题资源和窗口外壳辅助类，主窗口与设置窗口使用相同字体、表面和按钮规范。
2. 重构主窗口 XAML，调整搜索区、导航栏、结果条目和预览排版，补上等待状态和分隔条反馈。
3. 设置窗口改为五个分类，将现有控件和事件搬入对应分类，保留协议与持久化行为。
4. 适配现有 UI 自动化，增加融合标题栏、分类导航和紧凑布局检查。
5. 运行真实程序检查浅深色截图，修正文字、按钮、悬停和布局问题，再运行完整功能回归。
6. 生成新版本发布包，解压到项目目录之外，重复启动与界面验收，保存截图和校验值。

## 验收标准

- 主窗口与设置窗口的标题栏拖动、最大化、最小化、恢复和关闭可用，缩放后系统按钮不遮挡内容。
- 浅色、深色均正确显示官方图标和高亮；材质回退时正文仍可读。
- 主窗口最低约 800 × 620 DIP，设置窗口最低约 600 × 560 DIP；检查当前 125% 缩放和较宽窗口，记录实际像素尺寸。
- 长路径、文件名、错误信息和大段预览不使按钮溢出；设置各分类的全部操作可达。
- 原有 130 文件界面回归继续通过，包括搜索取消、分页、排序、历史、预览、复制路径、索引管理、目录切换、托盘、重连和退出。
- 最终交付为可运行 EXE、完整 ZIP、真实截图及验证记录；视觉完成度依据截图检查，不只依据编译结果。
